# Held-out cases

Made up like everything in `fixtures/`, and generated by `scripts/synth_cases.py` (`held_out()`).
They were written on 2026-11-06, before any model answered them, to test one change: a benign verdict
must cite the record of what happened, not only the record that says it was approved. That rule was
shaped by looking at Claude's and Qwen's answers to `../synthetic`, so scoring it there proves nothing.

They are new shapes on purpose: a DynamoDB role reading its own table and the same role listing others,
a scanner approved for an outside range, a second open port on an approved web server, a backup role
writing a bucket policy, and a role that no longer exists.

Once a change is tuned on these, they stop being held out. The next change needs new ones.
